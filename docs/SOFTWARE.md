# 软件设计

Halo Soundbar 是只面向 EDIFIER Halo Soundbar（VID `2D99` / PID `A063`）的 Windows USB 控制面板。

## 交互

| 功能 | 行为 |
|---|---|
| 音量 | 0–16，滑条调整；通过设备回读确认 |
| 音效 | 音乐 / 游戏 / 电影，回读确认并有限重试 |
| 氛围灯 | 开关决定下方灯效控件是否可用 |
| 灯光效果 | 七种效果，只有当前效果支持的参数允许调整 |
| 亮度 | UI 1–10；写入设备时乘以 10 |
| 速度 | UI 与设备均为 1–10，不乘以 10 |
| 自定义颜色 | 效果 1/3/4/6/7 支持；选色只保留草稿，点击“应用此颜色”才写入 |
| 颜色提示 | 说明显示屏和灯光硬件可能造成色差，以实际灯光为准 |
| 重置 / 关机 | 弹出确认对话框，取消不发送命令 |

切换灯效会清理前一个效果的编辑；切换页面前会发送最后一次滑条调整。
设备断开时禁用设备操作并取消尚未确认的对话框，后台继续尝试重连。

## 模块

| 模块 | 职责 |
|---|---|
| `ui.rs` | WinUI 界面，发送命令、接收设备快照，单独保存界面待确认值与颜色草稿 |
| `device.rs` | 后台设备会话、连接/重连、轮询、命令合并、音量和音效回读重试 |
| `hid.rs` | Windows HID 枚举、只匹配 Halo 控制接口、异步读写与超时取消 |
| `transport.rs` | `EcTransport` 接口及请求/应答匹配，供真设备和模拟测试共用 |
| `ec.rs` | EC 命令号和请求构造 |
| `protocol.rs` | 协议帧与基础解析 |
| `ec_state.rs` | 设备状态、灯效表解析、参数范围与控制语义 |

单个后台线程负责 HID 会话，避免 UI 阻塞。界面每 250 ms 接收状态并合并滑条操作。
后台进一步合并连续、同目标的设置命令，保留重置等操作的先后顺序。
颜色、亮度、速度需要写入完整灯效记录，因此会合并尚未得到设备回读的本地修改，但不包含未应用的颜色草稿。

## 同步与重连

空闲时按各自的到期时间选择一项轮询：音量 150 ms、灯效 300 ms、音效 400 ms。
这些是调度间隔，实际响应时间还取决于设备处理、等待和其他命令。
设备静默约 2 秒时做健康探测；写入失败或探测失败后重新枚举，未连接时约每 1.5 秒重试。

界面保留请求值以即时响应操作，但真实设备快照不被请求值覆盖。
待确认值超时后回到真实回读结果，断线时清理；音量和音效写入最多尝试三次。

## 构建与素材

使用 WinUI 3 的 `windows-reactor`，通过 Cargo 固定 Git 提交，提交 `Cargo.lock`。
应用图标及卡片图片编译进 exe。文件夹图标通过 PE 资源嵌入，窗口图标使用包含内容哈希的缓存路径，避免复用旧版本图标。

应用图标为独立绘制，卡片参考素材来源见 [第三方说明](../THIRD_PARTY.md)。

## 验证与限制

[TESTING.md](TESTING.md) 区分了自动测试、真机回读及尚未执行的操作。
当前只支持 USB；蓝牙和自定义 EQ 不在本项目当前实现范围内。
